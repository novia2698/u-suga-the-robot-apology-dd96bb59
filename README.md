A two-line robot confession for make.fun's "The Robot Apology" bounty: one
sentence owning a single concrete mistake — ironing a passport mistaken for a
shirt, its photo page melted shut — and one sentence naming the lesson that
mistake taught and the check that changes from now on. Winner takes all, so
the confession is written to be the most specific in the field, with a lesson
that follows from that exact slip.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=/tmp/out node main.ts && cat /tmp/out/entry.txt
```
